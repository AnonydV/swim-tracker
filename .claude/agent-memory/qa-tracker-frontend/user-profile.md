Développeur travaillant seul sur une application de tracking d'entraînement triathlon Half-Ironman personnelle (HIPLAN). L'app est en vanilla JS/HTML/CSS, sans framework ni test runner automatisé. Les tests sont manuels et exécutés dans le navigateur.

L'utilisateur maîtrise le JS frontend et la structure de l'application — les explications QA doivent être techniques et précises, avec des références aux lignes de code, noms de fonctions et clés localStorage exactes. Pas besoin de vulgarisation.

Langue de travail : français.
